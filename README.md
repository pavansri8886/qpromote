# QPromote

This repository contains a minimal, working prototype of the QPromote progressive deployment pipeline described in the thesis proposal.

It satisfies the minimum viable implementation requested in the review feedback:

- Stage 1: Bell-state validation on AerSimulator
- Stage 2: Bell-state validation on FakeManilaV2 using Hellinger fidelity and total variation distance
- Stage 3: demonstration stage on FakeSherbrooke
- SQLite evidence tracking for fidelity, TVD, gate count, qubit count, CFP, decision, and timestamp
- CLI entry point: `qpromote run pipeline.yaml`

## Quick start

1. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Run the pipeline:

   ```bash
   python qpromote.py run pipeline.yaml
   ```

   or, if your shell resolves the wrapper script:

   ```bash
   qpromote run pipeline.yaml
   ```

3. Inspect the evidence database:

   ```bash
   sqlite3 qpromote_evidence.db "SELECT * FROM evidence;"
   ```

## Files

- `qpromote.py` – CLI and implementation
- `pipeline.yaml` – sample pipeline definition
- `qpromote_evidence.db` – SQLite evidence store generated by the run

## Notes

This is intentionally compact and implementation-focused so that the prototype can be used as a concrete foundation for the thesis implementation chapter, experimental validation, and rebuttal materials.
